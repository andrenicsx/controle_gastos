# Fluxo — Controle de gastos

Aplicativo desktop em Python para registrar receitas e despesas por período.

## Como executar

1. Tenha o Python 3 instalado.
2. Abra um terminal nesta pasta.
3. Execute:

```powershell
python app.py
```

O aplicativo usa apenas a biblioteca padrão do Python. Os lançamentos são salvos automaticamente em `lancamentos.json`, criado ao adicionar o primeiro registro.
